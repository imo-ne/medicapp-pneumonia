. Data Preprocessing
Open and run the Processing_data.ipynb notebook.

This script preprocesses the raw chest X-ray images:

Resizes images to 224x224.

Normalizes pixel values to [0, 1].

Splits the data into train, val, and test sets.

Output: Preprocessed images are saved in data/processed/.

2. Data Balancing
Open and run the balance_data.ipynb notebook.

This script balances the dataset using SMOTE:

Generates synthetic samples for the minority class (PNEUMONIA).

Re-splits the balanced dataset into train, val, and test sets.

Output: Balanced dataset is saved in data/balanced/.

3. Model Training
Open and run the aug_train_resnet50.ipynb notebook (or the equivalent for EfficientNet/DenseNet).

This script trains the ResNet50 model:

Applies data augmentation (rotation, flipping, zooming, etc.).

Uses transfer learning with pre-trained ResNet50 weights.

Adds custom layers (GlobalAveragePooling2D, Dropout, Dense).

Compiles the model with the AdamW optimizer.

Trains the model and saves it as ResNet50_Pneumo1.keras.

Output: Trained model is saved in resnet50/model/.

4. Model Testing
Open and run the test_predict_rest.ipynb notebook.

This script tests the trained model on a single image:

Loads the trained model (ResNet50_Pneumo1.keras).

Preprocesses the input image and makes a prediction.

Generates Grad-CAM visualizations to interpret the model’s decision.

Output: Prediction results and Grad-CAM heatmaps.

Key Files and Outputs
Preprocessed Data: Saved in data/processed/.

Balanced Data: Saved in data/balanced/.

Trained Models: Saved in resnet50/model/, efficient_net/model/, and densenet/model/.

Grad-CAM Visualizations: Generated by test_predict_rest.ipynb.

Notes
Ensure the dataset is placed in data/chest_xray/ before running the preprocessing script.

The project is designed to be modular, so you can train and test different models (ResNet50, EfficientNet, DenseNet) by running the corresponding notebooks.
